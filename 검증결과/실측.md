# 무사히 실측 결과

- 측정일: 2026-11-10 · 재현: `python tools/measure.py` (모델·인터넷 불필요)
- 측정 환경: Linux x86_64, Python 3.13.18 (개발용 리눅스 컨테이너, 기관 PC에서 다시 재면 숫자가 달라질 수 있음)
- 대상: 정확도 성적표와 같은 작업 60건(A 30 + B 30)을 화면과 같은 API로 처리

| 항목 | 중앙값 | 최대 | 평균 |
|---|---|---|---|
| 위험성평가 1건 만들기(위험요인 찾기·가능성·중대성·작업 시작 판정) | 7.4ms | 14.5ms | 7.3ms |
| 위험성평가표 한글(HWPX) 만들기 | 96.9ms | 211.4ms | 102.2ms |
| TBM 기록지 한글(HWPX) 만들기 | 124.1ms | 188.3ms | 127.9ms |
| 담당자가 입력한 글자 수(작업명+작업 설명) | 17자 | 30자 | 17.3자 |
| 자동으로 채워진 위험요인 행 | 1개 | 4개 | 1.2개 |
| 자동으로 채워진 감소대책 | 4개 | 13개 | 4.3개 |
| 자동으로 붙은 판단 이유(조건·아차사고) | 0개 | 2개 | 0.2개 |
| 관련 기준(법령명·주제)이 붙은 위험요인 | 1개 | 4개 | 1.2개 |

- 처리 시간은 서버 응답까지 잰 값(화면 그리기 제외)입니다. 모델(솔라)을 켜면 AI 문장 기능은 모델 응답 시간만큼 더 걸립니다.
- **사람이 손으로 평가표를 쓰는 시간은 재지 않았습니다.** 비교하려면 같은 작업을 담당자가 기존 방식으로 쓸 때 걸린 시간을 기관에서 재야 합니다.
